# AI-DLC v2.10.0 Release Notes

> Source: https://github.com/awslabs/aidlc-workflows/releases/tag/v2.10.0  
> Published: 2026-09-24

## 핵심 요약

AI-DLC v2.10.0은 **Construction 단계의 검증 지점과 Human Authority를 강화**하고, 여러 Harness를 한 프로젝트에서 함께 사용할 수 있도록 개선한 릴리스입니다.

### 주요 변경점

- **Human Gate 강화**
  - Construction에서 검증된 Unit 및 Batch 단위 checkpoint를 기준으로 리뷰
  - Agent 실행 경계와 사람이 통제하는 Approval Gate를 더 명확하게 분리
  - 거부/복구 상황에서 다음에 실행할 수 있는 조치를 더 명확하게 안내

- **Harness 및 설정 개선**
  - 충돌하지 않는 여러 Harness를 한 프로젝트에서 함께 사용 가능
  - 공통 `AGENTS.md` onboarding block 공유
  - Amazon Bedrock을 명시적으로 선택하지 않는 한 기존 model provider 유지
  - Kiro IDE delegation, Copilot routing, compiled tool dispatch 경로 개선

- **Worktree / Lifecycle 안정성 개선**
  - Bolt branch, ref, worktree를 Intent 단위로 분리해 병렬 작업 충돌 방지
  - Park된 Bolt 작업 복구 안정성 개선
  - Git worktree에서도 Construction / CodeKB가 올바른 프로젝트를 인식
  - Windows drive-letter matching, hook PATH 및 doctor 관련 호환성 개선

## 업데이트

```bash
aidlc update
cd /path/to/project
aidlc config --yes
aidlc doctor
```

여러 Harness를 함께 사용하는 프로젝트라면 각 Harness별로 설정을 갱신합니다.

```bash
aidlc config --harness <name> --yes
```

## 현재 학습에서 볼 포인트

이번 릴리스에서 특히 확인할 부분은 **AI가 실행하고 사람이 Gate를 통제한다는 역할 분리**입니다.

```text
Agent 실행
   ↓
검증된 결과
   ↓
Human Approval Gate
   ↓
Approve / Revise / Reject
```

산책 코스 추천 POC에서도 앱 완성도보다 다음 항목을 우선 확인합니다.

- Construction checkpoint에서 어떤 결과를 검증하는지
- Gate에서 사람이 실제로 어떤 판단을 하는지
- 수정/거부 이후 workflow가 어떻게 복구되는지
- 판단과 수정 내역이 이후 workflow에 어떻게 반영되는지
